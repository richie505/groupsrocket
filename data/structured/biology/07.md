=== TOPIC biology:7 | Crop diseases and propagation

## Crop diseases and propagation methods | from: 58
# 1. Crop diseases
| Crop | Diseases |
|---|---|
| **Rice** (also called **paddy**) | **Blast**, **tungro**, **brown leaf spot** |
| **Wheat** | **Rust**, **smut**, **ear cockle** |
| **Sugarcane** | **Red rot** |
| **Potato** | **Early blight**, **late blight**, **black heart** |
| **Groundnut** | **Tikka** |
| **Mustard** | **White rust** |
| **Bajra** | **Green ear**, **ergot** |
| **Pigeon pea** | **Wilt** |
| **Citrus** | **Citrus canker** |
| **Cabbage** | **Black rot** |
| **Okra** | **Yellow vein mosaic** |
# 2. Causes
| Disease | Cause |
|---|---|
| **Citrus canker** | **Bacteria** |
| **Sugarcane red rot** | **Fungi** |
| **Wheat ear cockle** | **Nematodes** |
| **Potato black heart** | **Oxygen deficiency** |
# 3. Propagation
| Crop | Propagated by |
|---|---|
| **Sugarcane** | **Stem cuttings** or **setts**; **bud-chip setlings**; also **tissue culture** |
| **Banana** | **Suckers**; also **tissue culture** |
| **Potato** | **Tubers** |
| **Ginger**, **turmeric** | **Rhizomes** |
| **Garlic** | **Bulbs** |
| **Sweet potato** | **Tuberous roots** |
