=== TOPIC biology:10 | Nervous and skeletal systems

## Brain and nervous system | from: 37
# 1. Parts of the brain
| Part | Functions |
|---|---|
| **Cerebrum** — the **largest part** | **Thinking**, **memory**, **reasoning**, **sensation**, **speech**, **learning** |
| **Cerebellum** — the "**little brain**" | **Balance**, **coordination**, **posture**, **muscle control** |
| **Medulla oblongata** | **Heartbeat**, **breathing**, **swallowing**, **vomiting**, **coughing**, **sneezing** |
| **Hypothalamus** | **Body temperature**, **hunger**, **thirst**, **sleep**, **circadian rhythm** |
| **Brainstem** — includes the **pons** | **Automatic** and **vital** functions |
| **Hippocampus** | **Memory** |
| **Spinal cord** — the **reflex centre** | **Reflex action** |
- **Heart rate:** Regulated by the **medulla** and **brain autonomic centres**
- The **brain itself** has **no pain receptors**
# 2. Nerves
- **Cranial nerves:** **12 pairs** — associated with the **brain**
- **Spinal nerves:** **31 pairs** — associated with the **spinal cord**
| Nerve | Carries impulses |
|---|---|
| **Sensory** | **Receptors** → **central nervous system** |
| **Motor** | **Central nervous system** → an **effector** |
| **Mixed** | **Both** sensory and motor |
# 3. Divisions
- **Autonomic nervous system:** **Involuntary** functions
- **Somatic nervous system:** **Voluntary** functions — **skeletal muscles**
- **Reflex arc:** A **rapid involuntary response**

## Skeletal system | from: 38
# 1. Bones
| Bone | Location | Note |
|---|---|---|
| **Femur** | **Thigh** | The **longest bone** |
| **Tibia** | **Lower leg** | The **major weight-bearing** bone |
| **Fibula** | **Lower leg** | The **lateral leg bone** |
| **Humerus** | **Upper arm** | The **arm** |
| **Radius** | **Forearm** | **Thumb side** |
| **Ulna** | **Forearm** | **Little-finger side** |
| **Patella** | **Knee** | The **kneecap** |
| **Stapes** | **Middle ear** | The **smallest bone** |
| **Sternum** | **Chest** | **Supports** the **rib cage** |
| **Atlas** — **C1 vertebra** | — | **Supports** the **skull** |
| **Axis** — **C2 vertebra** | — | Enables **neck rotation** |
| **Ribs** | **Thorax** | **Protect** the **heart and lungs** |
| **Skull** | **Head** | **Protects** the **brain** |
| **Vertebral column** | **Back** | **Supports and protects** the **spinal cord** |
# 2. Numbers
- **Adult skeleton:** **206 bones**
- **Vertebrae:** **7 cervical**, **12 thoracic**, **5 lumbar**
- **Ribs:** The human body has **12 pairs** — **true ribs 1–7**; **false ribs 8–12**; **floating ribs 11–12**
# 3. Functions
- **Support** — the **skeleton**; **movement** — **bones and muscles**; **protection** — the **skull and rib cage**
- **Storage:** Bones **store calcium and phosphorus**; **yellow bone marrow** **stores fat**
- **Red bone marrow:** **Forms blood cells**
