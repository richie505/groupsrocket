## Hosts, reservoirs and zoonoses | from: 18, 19
# 1. Parasite life cycles
| Parasite | Hosts / vector | Disease |
|---|---|---|
| **Plasmodium** | **Humans** as hosts; **female Anopheles** — the **vector**; **humans** and **mosquitoes** form the **malaria cycle** | **Malaria** |
| **Leishmania** | **Sandflies**; **dogs** — **reservoirs** | **Kala-azar** |
| **Trypanosoma** | **Transmitted** by the **tsetse fly** | **Sleeping sickness** |
| **Wuchereria bancrofti** | **Culex mosquitoes** | **Filariasis** |
| **Ascaris lumbricoides** | **Humans** as hosts | **Ascariasis** |
| **Taenia solium** | **Humans** as hosts; associated with **pork** | **Taeniasis**; **neurocysticercosis** |
| **Schistosoma** | A **snail** — the **intermediate host** | **Schistosomiasis** |
| **Fasciola** | **Cattle** and **sheep** — **main hosts** (and **other ruminants**) | **Fascioliasis** |
| **Dracunculus medinensis** | **Humans** as hosts; **Cyclops** | **Guinea worm disease** |
# 2. Animal hosts and reservoirs
| Disease | Reservoirs / animal hosts |
|---|---|
| **Rabies** | **Dogs**, **cats**, **bats**, **foxes** and **other wild animals** |
| **Japanese encephalitis** | **Domestic pigs**; **wild birds** |
| **Plague** | **Rats and fleas** — the **rat–flea cycle** |
| **Ebola** | **Animals**; **non-human primates** |
| **Nipah** | **Animal-associated** — **pigs** discussed as a **source** |
| **SARS** | **Animal origin** — **animal-associated** |
| **Foot-and-mouth disease** | **Cattle**, **sheep**, **goats**, **pigs** |
| **Rinderpest** | **Cattle**; **buffalo** |
| **Bird flu** | **Birds and poultry** |
| **Swine flu** | **Pigs** — **important hosts** |

## Vaccines | from: 19
| Vaccine | Protects against / fact |
|---|---|
| **First polio vaccine** | Developed by **Jonas Salk** |
| **Oral Polio Vaccine** | Developed by **Albert Sabin** — **trivalent OPV**: **poliovirus types 1, 2 and 3**; **bivalent OPV**: **types 1 and 3** |
| **BCG** | **Tuberculosis** |
| **Toxoid vaccine** | **Prevents** **diphtheria** |
| **DPT** | **Diphtheria**, **pertussis** and **tetanus** |
| **RTS,S/AS01** | A **malaria vaccine** — the **first WHO-approved** malaria vaccine in the source |
| **R21/Matrix-M** | A **malaria vaccine** — **collaboration** between the **Oxford Jenner Institute** and the **Serum Institute** |
| **Covishield**, **Covaxin**, **Sputnik V**, **Moderna** | **COVID-19 vaccines** |
| **ZyCoV-D** | A **DNA-based** **COVID-19 vaccine** |
| **Hepatitis B** | **Has** a vaccine |
| **AIDS** | ⚠ The **source** does **not attribute** a vaccine |
