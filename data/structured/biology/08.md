=== TOPIC biology:8 | Human body - organs, digestion, enzymes and hormones

## Major organs — location and function | from: 29
| Organ | Location | Functions |
|---|---|---|
| **Brain** | **Cranial cavity** | **Coordination**, **thinking**, **balance**, **vital functions** |
| **Heart** | **Between the lungs** — the **mediastinum** | **Pumps blood** |
| **Lungs** | **Thoracic cavity** | **Respiration**; **gas exchange** |
| **Liver** — the **largest gland** | **Abdominal cavity** | **Produces bile**; **stores glycogen**; **forms urea** |
| **Pancreas** | **Abdominal cavity** | **Digestive** and **endocrine** functions |
| **Stomach** | **Upper abdomen** | **Digestion** — **gastric enzymes** |
| **Small intestine** | **Abdominal cavity** | **Major digestion**; **absorption** |
| **Large intestine** | **Abdominal cavity** | **Absorbs water** |
| **Kidneys** | **Either side** of the **vertebral column** | **Filter blood**; **form urine** |
| **Spleen** | **Abdominal cavity** | **Filters blood**; **removes old red blood cells**; an **immune role** |
| **Bone marrow** | **Inside bones** | **Produces** **red blood cells**, **white blood cells** and **platelets** |

## Digestion and enzymes | from: 29, 30
# 1. Digestive juices
| Source | Secretion | Contents / action |
|---|---|---|
| **Mouth** — **salivary glands** | **Saliva** | **Salivary amylase** (**ptyalin**) — **digests starch** |
| **Stomach** | **Gastric juice** | **Pepsin** — **digests proteins** into **peptides**; **rennin** — **milk curdling and digestion** (the source emphasizes this); **hydrochloric acid (HCl)** — an **acidic medium**; **activates pepsin** |
| **Liver** | **Bile** | **No digestive enzyme** — **emulsifies fats**; **stored** in the **gallbladder**, which **releases** it into the **duodenum** |
| **Pancreas** | **Pancreatic juice** | **Trypsin** — **proteins**; **amylase** — **carbohydrates**; **lipase** — **fats** |
| **Small intestine** | **Intestinal juice** | **Various enzymes** — **final digestion**; **lactase** — **digests lactose** |
# 2. Enzymes and their sources
| Enzyme | Source | Action |
|---|---|---|
| **Ptyalin** (**salivary amylase**) | **Salivary glands** | **Starch** |
| **Amylase** | **Salivary glands** and **pancreas** | **Starch** |
| **Pepsin** | **Stomach** | **Proteins** → **peptides** |
| **Rennin** | **Stomach** | **Curdles milk** |
| **Trypsin** | **Pancreas** | **Proteins** |
| **Lipase** | **Pancreas** and **intestine** | **Fats** |
| **Lactase** | **Small intestine** | **Lactose** |
| **Thrombin** | **Blood coagulation system** | **Converts** **fibrinogen** into **fibrin** |
| **Renin** | **Kidney** | **Acts** on **angiotensinogen** in the **RAAS** |
| **Nitric oxide synthase** | **Endothelium** and **other tissues** | **Produces** **nitric oxide** — made by **blood-vessel endothelium**; causes **vasodilation** |

## Endocrine glands and hormones | from: 29, 30, 31
# 1. Glands — location and hormones
| Gland | Location | Hormones |
|---|---|---|
| **Pituitary** — the **master gland** | **Brain** | **Tropic hormones** — **GH**, **FSH**, **LH**, **prolactin**, **TSH**, **ACTH**, **ADH**, **MSH**, **oxytocin** |
| **Pineal** | **Brain** — **epithalamus** | **Melatonin** — **regulates** the **biological clock** |
| **Thyroid** | **Front of the neck** | **T3**, **T4**, **calcitonin** |
| **Parathyroid** | **Dorsal side** of the **thyroid** | **Parathyroid hormone (PTH)** — **parathormone**; **regulates calcium** |
| **Thymus** | **Behind the sternum**, **between the lungs** | **Thymosin**, **thymopoietin** — **T-cell development** |
| **Adrenal glands** | **Above the kidneys** | **Cortex:** **aldosterone**, **cortisol**, **androgens**; **medulla:** **adrenaline**, **noradrenaline** |
| **Pancreas** | — | **Insulin**, **glucagon** |
| **Testes** | **Scrotum** | **Sperm**; **testosterone** |
| **Ovaries** | **Pelvic** or **abdominal cavity** | **Ova**; **estrogen**; **progesterone** |
| **Placenta** | — | **Chorionic gonadotropin** |
| **Kidney** | — | **Erythropoietin** |
| **Stomach** / **intestine** | — | **Gastrin** / **secretin** |
# 2. Hormone actions
| Hormone | Produced by | Action |
|---|---|---|
| **T3 / T4** | **Thyroid gland** | **Regulates metabolism** |
| **Calcitonin** | **Thyroid gland** | **Decreases blood calcium**; **promotes bone formation** |
| **PTH** | **Parathyroid glands** | **Increases blood calcium** |
| **Adrenaline** | **Adrenal medulla** | **Fight-or-flight** response |
| **Noradrenaline** | **Adrenal medulla** | **Stress response** |
| **Aldosterone** | **Adrenal cortex** | **Sodium and water balance**; **blood pressure** |
| **Cortisol** | **Adrenal cortex** | **Stress response**; **glucose metabolism** |
| **GH** (**somatotropin**) | **Pituitary gland** | **Promotes growth** |
| **TSH** | **Pituitary gland** | **Stimulates** the **thyroid gland** |
| **ACTH** | **Pituitary gland** | **Stimulates** the **adrenal cortex** |
| **FSH** | **Pituitary gland** | **Follicle growth**; **spermatogenesis** |
| **LH** | **Pituitary gland** | **Ovulation**; **testosterone production** |
| **Prolactin** | **Pituitary gland** | **Milk production** |
| **ADH** (**vasopressin**) | **Released** by the **pituitary gland** | **Water reabsorption** |
| **MSH** | **Pituitary gland** | **Regulates melanin** |
| **Oxytocin** | **Released** by the **posterior pituitary** | **Uterine contraction**; **milk ejection** |
| **Melatonin** | **Pineal gland** | **Circadian rhythm**; **sleep** |
| **Thymosin** | **Thymus** | **T-cell maturation** |
| **Insulin** | **Beta cells** of the **pancreas** | **Decreases blood glucose** |
| **Glucagon** | **Alpha cells** of the **pancreas** | **Increases blood glucose** |
| **Testosterone** | **Testes** | **Male secondary sexual characters** |
| **Estrogen** | **Ovary** and **follicles** | **Female secondary sexual characters** |
| **Progesterone** | **Ovary** and **corpus luteum** | **Supports pregnancy** and the **uterus** |

## Endocrine disorders | from: 31
| Hormone | Deficiency causes | Excess causes |
|---|---|---|
| **Thyroxine** | **Cretinism**; **myxoedema**; **goitre** | **Graves' disease**; **exophthalmia**; **Plummer disease** |
| **PTH** (**parathyroid hormone**) | **Low** / **decreased blood calcium**; **tetany and cramps** | **Fragile bones**; **osteoporosis**; **kidney stones**; **increased blood calcium** |
| **GH** | **Growth retardation**; **dwarfism** | **Gigantism** in **children**; **acromegaly** in **adults** |
| **ADH** | **Diabetes insipidus** — **excessive urine output** | **Decreased urine output** |
| **Cortisol** | **Addison's disease** | **Cushing disease** |
| **Insulin** | **Diabetes mellitus** | **Hypoglycaemia** |
| **Adrenal androgen** | — | **Adrenal virilism** |
