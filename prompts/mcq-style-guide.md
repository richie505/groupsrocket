# APPSC Group 2 — MCQ Format Guide

This file captures **format**, not content. Every PYQ carries a keyword tag (from `blueprint-keywords.md`) *and* a format tag from this list — the two are independent. A "Founder/founded" keyword can show up as a plain direct-recall question one year and as an Assertion-Reason question the next.

Confirmed from the 2025 Group II Mains Paper I (150 Qs, AP History + Indian Constitution). Percentages below are rough shares observed in that one paper — treat as a starting signal, not a fixed ratio, until more papers are tagged.

## 1. Direct Recall (single best answer)
Plain fact-retrieval, 4 options, one correct. The largest single category.
- Example shape: "Who was the founder of X?" / "Where was X located?" / "In which year did X happen?"

## 2. Negative / "Incorrect" Statement
Same as direct recall but inverted — asks which statement is *false* or *incorrect*, or "not true." Requires knowing the correct fact well enough to spot the deliberately wrong option among 3–4 true ones.
- Example shape: "Which of the following statements is incorrect?" followed by 4 factual claims.
- Design note: distractors here are usually true statements with one detail altered (a date, a place, a name) — not implausible statements.

## 3. Assertion–Reason (A/R)
Two statements, "Assertion (A)" and "Reason (R)." Four fixed answer choices every time:
1. Both A and R true, R correctly explains A
2. Both A and R true, R does NOT correctly explain A
3. A true, R false
4. A false, R true
This format appeared extremely frequently across both sections — treat it as a core format to generate practice for, not a rare edge case.

## 4. Statement-Based (Statement A / Statement B)
Similar to Assertion-Reason but the two statements are independent claims, not assertion+justification. Four choices: both true / both false / A true-B false / A false-B true.

## 5. Multi-Statement Correctness (I, II, III...)
Three or more numbered statements; options are combinations like "I and II only," "II and III only," "I, II, III." Tests whether the candidate can evaluate several claims independently rather than just recall one fact.

## 6. Chronological Ordering
4 items (rulers, events, committees, parties) to be arranged in correct time order; answer choices are ordering codes (e.g. "D, C, B, A"). Tests sequence/timeline knowledge, not just isolated facts.

## 7. List-Matching (List-I / List-II with codes)
Two columns (e.g. Authors↔Works, Inscriptions↔Rulers, Committees↔Recommendations, Constitution-source↔Provision-adopted). Answer choices are code combinations (e.g. a-iii, b-iv, c-ii, d-i). This is one of the most common formats and pairs with almost any keyword — anything that has a natural pairing (person↔place, item↔date, cause↔effect) can be tested this way.

## 8. Count-Based
"How many of the following are X?" with a short list, answer choices are numbers (4/1/3/2). Distinct from multi-statement correctness because it asks for a quantity, not which combination is correct.

## Notes for generating new practice questions
- When generating a new MCQ for a keyword, pick a format from this list rather than defaulting to plain direct-recall every time — the real paper leans heavily on A/R, list-matching, and negative-statement formats.
- Distractors should be genuinely close (a different date, a related-but-wrong person, an adjacent state) — not obviously wrong options.
- Match the format mix seen in `pyq-bank.md` for that specific keyword when known, rather than assuming uniform format distribution across the whole syllabus.
